## 实现

- 复用已验证 Open5GS image 作为基底，只给 UPF 派生镜像增加 nftables 及固定版本依赖；宿主没有安装软件包或改写规则。
- nftables 仅在 UPF 容器内建立 `ip aoc_v2` 表。NAT 限定源 `10.0.0.0/24` 和出口 `eth0`，不 flush 其他表、不修改宿主防火墙。
- UPF 的 `ogstun` 为 `10.0.0.1/24`，容器内启用 IPv4 forward；所需能力限定 NET_ADMIN 和探测用 NET_RAW，无 privileged/host network。
- SMF 下发 DNS 配置为 `1.1.1.1`，只配置 `oai` IPv4 池。此处未冒称已验证 UE DNS 下发。
- 新核心网内部实际候选采用 `172.28.81.0/24`，避开仍归旧部署所有的 `172.28.80.0/24`。N6/UPF `.14`，ext-DN `.15:5201`。原内部网桥未删除。
- ext-DN 使用 Open5GS 构建镜像自带的 iperf3 3.16，不读取旧测速脚本或旧镜像。

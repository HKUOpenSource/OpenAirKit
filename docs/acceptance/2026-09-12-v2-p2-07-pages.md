# V2 P2-07 页面与诊断导出验收记录

日期：2026-09-12

## 页面范围

- 英文界面保留 Overview、gNB、Core Network、Devices、History 和 Diagnostics 六个主页面，桌面侧栏与移动导航使用同一套入口。
- Overview 展示主机、B210、gNB、N2 与主要 NF 拓扑，并链接到相应页面或组件详情。
- gNB 页面展示运行状态、配置、B210、无线 context 和可用趋势；缺少的调度字段保持 `unavailable`。
- Core Network 页面展示限定 Open5GS NF、N2/N3/N4/N6 证据与 N3/N6 流量。每个 NF 使用独立 `/components/:id` 路由，支持刷新和返回。
- Devices 支持订阅设备与未关联无线 context 分栏、搜索、状态筛选及独立详情路由。详情只展示网络侧注册、数据 PDU 和经过验证的关联信息。
- History 支持实体、指标、时间、事件级别过滤，趋势按聚合接口读取，事件使用游标加载更早记录。

## 诊断边界

诊断导出由鉴权后端生成，递归移除 SUPI/IMSI/IMEI/SUCI、地址、TEID、PID、InvocationID 和 B210 序列号等字段。前端不直接导出内存中的原始快照。

默认页面不展示 Jetson 的 RNDIS、路由或端到端探测。可选 ICMP 诊断处于折叠区域并明确标注测量点为 Spark ext-DN 容器；不把结果表示为 Jetson 侧数据路径，也不显示目标 UE 地址。

# Jetson 故障排查

## 执行器不可用

先用已安装管理器检查两个单元，再查看设备服务 journal。确认发布路径存在、Python
模块能从已安装后端导入，Unix socket 的所有者和权限与 Web 服务匹配。不要用通用
特权 shell 绕过 socket。

## 串口被占用

进入维护模式，停止当前持有者，并确认发现到的 AT 设备已释放。执行器同时使用进程
锁与串口排他打开；未检查进程就删除锁可能产生两个写入者。

## 注册或 PDU 失败

依次读取 SIM、服务小区、`C5GREG`、上下文定义、激活和地址证据。已注册但地址为
`0.0.0.0` 不代表数据会话有效。只有配置回读符合网络契约后才允许执行一次重连。

## 数据路径失败

确认当前模组接口、IPv4 地址、到配置探测目标的路由和受保护管理路由。探测必须绑定
该接口。未绑定的 ping 可能走 Wi-Fi，不能作为验收依据。

## 测速失败

分别保留上下行错误。等待上一 iperf3 控制会话关闭，检查目标服务，并在取消后确认
无残留子进程。部分结果和任务标识必须保留。
